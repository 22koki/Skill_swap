# SkillSwap MVP

SkillSwap lets people exchange knowledge instead of money.

Core journey:
1. Create profile
2. Add skills you can teach
3. Add skills you want to learn
4. Discover complementary users
5. See a match score
6. Propose a swap
7. Accept/decline/counter
8. Book sessions
9. Chat
10. Complete the swap
11. Rate and review

Signature feature: two-way skill matching.
Example: Python ↔ Photography.

Planned stack:
- React + Vite frontend
- Django + DRF backend
- PostgreSQL
- JWT authentication
- Django Channels for realtime chat
